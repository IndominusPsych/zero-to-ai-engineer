## What you'll learn

- The anatomy of a good prompt
- Principle 1: Be clear and specific
- Principle 2: Give context and explain *why*
- Principle 3: Use structure and delimiters
- Principle 4: Show, don't just tell: zero-shot and few-shot
- Principle 5: Let it think: chain-of-thought
- Principle 6: Specify the output format
- Principle 7: Give the model an "out"
- System prompts vs user messages
- Prompt templates and variables
- Breaking big tasks apart: prompt chaining
- Long documents
- Prompt injection: a security warning
- Iteration and evaluation
- Model differences
