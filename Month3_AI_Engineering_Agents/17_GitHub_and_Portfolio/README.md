## Quick setup

```bash
gh auth status
# create your portfolio site repo
cd ~/ai-engineer-projects
mkdir <your-username>.github.io && cd <your-username>.github.io
git init
gh repo create <your-username>.github.io --public --source=. --remote=origin
```
