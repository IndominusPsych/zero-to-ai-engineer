## What you'll learn

- Data, features and labels
- The model
- Training and prediction
- Types of machine learning
- Loss: how wrong is the model?
- Gradient descent: how models learn
- Train / test split: honest evaluation
- Overfitting and underfitting
- Feature engineering and preprocessing
- A tour of common algorithms
- Neural networks in one minute
- Evaluation metrics
- scikit-learn: the toolbox

## Quick setup

```bash
cd ~/ai-engineer-projects
uv init ml_practice && cd ml_practice
uv add scikit-learn pandas numpy matplotlib joblib
uv add --dev ipykernel      # optional, for notebooks
```

Full details, a "check it works" command and fixes for common problems are at the top of [lesson.md](lesson.md) and in the [Setup Guide](../../00_SETUP_Install_Guide.md).
